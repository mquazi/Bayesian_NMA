# Bayesian Network Meta-Analysis in R 

This repository contains the R code and datasets used in the tutorial on Bayesian network meta-analysis (BNMA) using the `BUGSnet` package.

## Examples

Two examples are included:

- **Diabetes:** Binary outcome examining incident diabetes across antihypertensive treatments.
- **Hepatectomy:** Continuous outcome examining estimated blood loss across open, laparoscopic, and robotic hepatic resection.
